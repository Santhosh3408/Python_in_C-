# Python in C++

A console-based Snake Game developed using C++ with real-time movement, collision detection, dynamic snake growth, and difficulty levels.

---

## Features

- Real-time snake movement
- Snake growth after eating food
- Random food spawning
- Self collision detection
- Wall collision detection
- Live score tracking
- Difficulty selection
- WASD controls
- Arrow key support
- Quit option during gameplay

---

## Controls

| Key | Action |
|------|--------|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| Q | Quit Game |

---

## Technologies Used

- C++
- STL Vector
- Console Rendering
- Real-time Keyboard Input

---

## How to Compile and Run

```bash
g++ Python_in_C++.cpp -o snake
.\Python_in_C++
```

---

## Game Rules

- Eat food to grow the snake.
- Avoid hitting walls.
- Avoid colliding with your own body.
- Higher difficulty increases game speed.
